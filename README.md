# PrestaShop Docker Setup

Docker Compose setup for running PrestaShop with MySQL on Ubuntu.

## Services

- PrestaShop
- MySQL 8.0

## Requirements

- Docker
- Docker Compose
- Ubuntu Linux

## Configuration

Create a `.env` file containing the database credentials:

```env
MYSQL_ROOT_PASSWORD=your_root_password
MYSQL_DATABASE=prestashop
MYSQL_USER=prestashop
MYSQL_PASSWORD=your_password
